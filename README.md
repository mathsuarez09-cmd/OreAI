# OreAI. TurboWarp and PenguinMod Extension

**OreAI** is an extension for TurboWarp and PenguinMod. It brings artificial intelligence models like Google Gemini and OpenAI into your Scratch projects.

## Features

- **New Models:** OreAI supports gemini-3.5-flash, gemini-3.1-flash-lite, gpt-5.4-mini and gpt-5.4 models and etc.

- **Your Model:** You can use any model you want with the set custom model ID block.

- **Custom Prompts:** You can change how your artificial intelligence assistants or game characters talk.

- **Error Checking:** There is an error block to help you fix problems with your API key or internet connection.

## How to Load

1. Open. Penguinmod.

2. Click the + Add Extension button at the bottom left.

3. Choose Custom Extension.

4. Upload OreAI.js. Copy and paste its contents into the Text tab.

5. Remember: You need to check "Run extension without sandbox" so the API requests work.

## Security Notice

Do not share your Scratch project files or packaged programs with your API keys, in them. Always ask users to enter their API key or load it from a safe place that you do not share. OreAI and TurboWarp and PenguinMod are important to use. Always remember to keep your API keys safe when you use OreAI and TurboWarp and PenguinMod.
